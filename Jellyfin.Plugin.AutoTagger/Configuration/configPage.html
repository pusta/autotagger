Tags by library

Enter the tags to apply to items added to each library, separated by commas. Leave a library's tags empty to skip it. Existing tags are never removed. If an item already carries one of a library's skip tags, that library's tags are not applied to it. Note that listing a tag in both boxes makes the library tag its items once and then leave them alone.
